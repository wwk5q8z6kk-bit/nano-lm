## Primary research: exact identities and transfer limits

1. **Zhou et al., [Value Residual Learning](https://aclanthology.org/2025.acl-long.1375/), ACL 2025**, DOI 10.18653/v1/2025.acl-long.1375; earlier [arXiv:2410.17897](https://arxiv.org/abs/2410.17897) initial submission 2024-10-23. The abstract describes ResFormer with first-layer value residual and SVFormer sharing values. Prior art for the *mechanism*; reported data efficiency at other sizes must **not** be treated as a Nano result.
2. **He et al., [Do Value Vectors in Deep Layers Need Context from the Residual Stream?](https://aclanthology.org/2026.emnlp-main.1784/), EMNLP 2026**, DOI 10.18653/2026.emnlp-main.1784. Their Bank of Values contrasts contextual vs context-free value states and provides a stronger mechanistic comparator; not evaluated here.
3. **Zeng et al., [Depth-Attention: Cross-Layer Value Mixing for Language Models](https://arxiv.org/abs/2606.05014), arXiv:2606.05014 (2026-06-03)**. Author-reported cross-layer value mixing and efficiency on larger Qwen-like models. It is a reference family, not established as a Nano LM win. This inspection relies on published abstracts/introduction, not a complete independent reproduction.
4. For placement, Lan et al., [On-Policy Morphing into Hybrid Attention Models](https://arxiv.org/abs/2611.24809), arXiv:2611.24809 (2026-11-18), remains the key recent on-policy recovery comparator already recorded in PR #210. No novelty claim about fixed leave-one-out ranking should bypass this work.
