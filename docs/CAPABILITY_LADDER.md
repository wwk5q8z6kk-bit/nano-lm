# Capability Ladder

Nano advances through **nine programs**. Do not skip ordering because a frontier model can superficially perform a later stage.

```text
P1 — SCRIBING          What happened?
        ↓
P2 — SUMMARIZATION     What matters?
        ↓
P3 — CHARTING          What is the state, and how has it changed?
        ↓
P4 — SYNTHESIS         What does the combined evidence show?
        ↓
P5 — QUESTIONING       What is unknown, missing, or ambiguous?
        ↓
P6 — REASONING         What follows from the evidence?
        ↓
P7 — PLANNING          What should happen next?
        ↓
P8 — TOOLS / ACTION    What external action should be performed?
        ↓
P9 — ADAPTATION        What did outcomes teach us?
```

A system that reasons from corrupted state is not intelligent enough for our purposes.

## Program summary

| Program | Objective | Must master before advancing |
|---------|-----------|------------------------------|
| **P1 Scribing** | Faithful encounter record / note | exact values, evidence, negation, uncertainty, temporality, structure |
| **P2 Summarization** | Compress without corruption | salience, hierarchy, omission control, provenance |
| **P3 Charting** | Longitudinal state | identity, timelines, supersession, contradictions |
| **P4 Synthesis** | Cross-source integration | provenance graphs, conflicting evidence |
| **P5 Questioning** | Information gaps | uncertainty, disambiguation |
| **P6 Reasoning** | Bounded conclusions | explicit premises, calibrated uncertainty |
| **P7 Planning** | Future actions | goals, constraints, consequences |
| **P8 Tools/Action** | Environment interaction | routing, execution, permissions |
| **P9 Adaptation** | Learning from outcomes | memory update, architecture feedback |

## Current frontier
