# Wedge v1 — Inclusion / exclusion predicates (I* / X*)

**Frozen before any classical scores.** Anti-circular (E4 lesson / WEDGE_V1 B4).

## I* — inclusion (process)

1. Documents are **synthetic** Markdown generated by `build_corpus.py` with fixed seed.
2. Domain mix: technical notes + biomedical-style abstracts (fake entities only).
3. Each doc has stable `doc_id`, headings, and planted atoms listed in gold.
4. Total extracted text << 5 MB (v1 target < 100 KB).
5. License: original synthetic text; no scraped papers; no PHI.

## X* — exclusion

1. No real clinical notes / PHI / patient identifiers.
2. No old scribe template families (CC|DUR|SEV|MED|ALG isomorphic worlds).
3. No documents selected because a classical solver already failed.
4. No post-hoc dropping of instances after seeing solver scores.
5. No cloud-hosted corpus requirement.

## B* — classical stress probe (sanity, not cherry-pick)

Before declaring the slice too easy, report:

- B1: >=1 multi-doc numeric contradiction planted (T29).
- B2: >=1 entity-type collision planted (T30).
- B3: >=1 missing-field abstain case (T34).
- B4: >=1 paraphrastic query without lexical overlap (T35) — classical may abstain.

If fewer than 2 of {B1..B4} are present in the frozen corpus -> VOID rebuild.
