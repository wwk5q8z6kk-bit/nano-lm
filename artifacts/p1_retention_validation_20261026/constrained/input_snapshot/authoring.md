# Fresh synthetic retention validation cohort

Created on 2026-10-26 by an independent AI author. The author is not a human clinician, and these dialogues are not clinician-validated encounters. Every person, event, history, and statement is artificial. The material is development validation input, not medical advice or a record of patient care.

The author read the provided agent instructions and the independent semantic annotation rubric at `artifacts/p1_scope_validation_20261023/annotation_rubric.md`. The author did not read implementation, tests, prior source cases, prior annotations, generated annotations, model outputs, or previous validation results. The coordinating agent confirmed that the required shared harness core had already been read during the session. No production extraction or annotation was run by this author.

The cohort contains 24 new dialogues, four in each of six requested strata. Each dialogue contains 6–12 speaker turns. The coordinator requested `Doctor:` and `Patient:` role labels to match the input format, with sparse `Other:` turns. Wording was composed afresh with varied question ordering, short and expanded responses, compound questions, volunteered details, and occasional interruptions.

The design covers current complaints, duration, severity, treatment attempted for the current complaint, and medicine or material allergies. It intentionally includes explicit treatment/allergy absences, fields left unreported, local uncertainty alongside clear facts, unresolved inconsistent reports, explicit corrections, unrelated personal history, and statements by other people. These are authoring intentions rather than independently verified label counts; independent annotation must establish the semantic distribution.

Only `sources.json` and this provenance note were authored. The source file contains case identifiers, coarse design strata, and transcripts; it contains no gold labels, evidence spans, expected extraction results, or annotation rationales. Structural checks cover JSON validity, unique identifiers, balanced stratum counts, speaker labels, and turn counts. They do not establish semantic correctness or clinical realism.
