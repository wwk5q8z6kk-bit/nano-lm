# Frozen public-language comparison

Each frozen seed-zero S2, M0 and M2 predicts the same tokenized text. The main comparison is M2 minus M0 in bits per UTF-8 byte (lower is better). S2 differs in parameter and training-token budget. Report every document and source, the pooled byte-weighted result, and a stratified paired bootstrap interval for that pooled difference (2,000 draws, seed 20261120).

Use the staff economic situation section of each of the eight scheduled 2025 FOMC minutes, the enacting text of US public laws 119-1 through 119-8, and discussion number 3 from 2025 Atlantic storms AL01 through AL08. Use fixed document order and at most 1,024 tokenizer IDs per document, clipping to a valid round-tripping UTF-8 prefix. Collapse whitespace and normalize to Unicode NFC. Include short documents. Fail closed on missing or changed documents; record any protocol deviations before scoring.

Use the historical shared 32k tokenizer, start each document with the training EOS ID, reset context every 256 targets and predict all targets once. At subsequent blocks the first input is the previous token. Compare natural order with a fixed within-block permutation seeded from the document ID. Both conditions use the natural document's byte denominator. The shuffled condition measures sensitivity to token order. A Laplace-smoothed unigram fitted on every hundredth token starting at zero in the original 800M-token mixed training stream is the common reference. Check every full passage and its initial, central and terminal 32-token anchor against the aligned mixed training stream. Exclude fully duplicated passages from the comparison and report partial anchor overlap. These are descriptive diagnostics on three publishers.
