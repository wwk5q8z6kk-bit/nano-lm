## 2. Ten Largest Technical Limitations (Task D)

1. **Dual Vocabulary Unembedding Tax in `X8` ATRD:** Evaluating `logsumexp` + `topk(lg1)` over `V = 32,768..65,536` twice per forward pass burns more GEMM FLOPs on the classifier head than Pass-2 saves, slowing `X8` by `1.81x` (`47M`) and `2.65x` (`125M`) relative to single-unembed baselines.
2. **Contractive State Transport vs. Non-Commutative Composition:** Standard DeltaNet (`beta in (0, 1)`) and pure linear/wave attention (`P1/P2`, `I3_HRWN`) cannot represent parity/inversion reflections ($\det < 0$), collapsing on multi-step finite-group state tracking (`OOD_Comp = 0.176` vs `0.739–0.751`).
3. **Closed-Entity Slot Ceiling (`M0..M11`) in Cognitive Workspaces:** Hardcoding 12 module embeddings makes general out-of-distribution generalization above `N = 12` entities structurally impossible without aliasing or `IndexError`.
4. **In-Distribution Anchor/Identity Gap in `G3_HMWR` (`-0.0154 BPB` vs. `B0`):** Without Per-Head Layer-0 `Gated-VRes` and `QK`-RMSNorm, compressed WY + Wave channels trailed GQA slightly on raw exact token copying (`web`/`math` ID BPB); adding `Gated-VRes` + `QK-RMSNorm` in `G4` closed this gap completely (`2.1112` vs `2.1188`).
5. **Hardcoded Action-Index Shields Instead of Learned Decision-Theoretic Risk:** `suff_pen[4]` and `suff_pen[6]` couple cognitive safety to environment action numbering (`ACT_PATCH=4`, `ACT_STOP=6`) rather than transferable Expected Free-Energy minimization.
6. **Disconnected Symbolic Verification & Neural Uncertainty:** Canonical `nano/` provenance (`Identity`, `EpistemicStatus`, `CausalLink`) sits isolated in deterministic unit harnesses instead of governing neural memory queries, contradiction handling, and causal claims at runtime.
7. **Hint-Dependent / Keyword-Brittle System Routing & Fixed Call Budgets:** `NanoLMSystem` routes via `task_hint` or naive keywords, missing paraphrased quantitative problems while wasting 3+ LLM calls on already-certified computations.
8. **Un-Fused Python Dispatch & Unchunked Prefill Memory Spike (`G3`/`G4`):** Pure Python loops over `n_chunks = 2048` (`ctx = 32,768`) push single-shot prefill peak VRAM to `7.88 GiB` on `222M` T4 despite only `13.22 MiB` persistent recurrent state.
9. **Short-Horizon Optimization Misattribution (`250` vs. `1,000+` Steps):** Fixed `250`-step screening systematically over-rewards fast-aligning convolutions (`I3_HRWN`) and under-estimates gated/orthogonal architectures and pure-CE `Muon` late-stage steepness.
10. **Absent End-to-End Flagship Pretraining & Clinical/Real-Repo Grounding (`<4B` Scale):** While architecture census (`3.88B`), hardware latency, and `20.55M–125M` learning dynamics are established, full Chinchilla-scale pretraining (`50B–100B` tokens) and real human dual-IAA NanoScribe grounding remain unexecuted.
